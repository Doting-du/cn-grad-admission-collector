## ⑦ 描述

```
【解决什么问题】
考研招生人数散落在各校研究生院、研招网与学院官网，格式各异、口径混乱：同一专业的"拟招生人数"可能是学院总数，也可能含推免；9 月发布的专业目录常被 10 月调整公告修改。手工整理一个省往往要几天，且极易把"学院总数"当成"专业人数"。

【这个技能怎么做】
按你指定的年份与学校范围，逐校打开官方招生简章、专业目录、招生计划与调整公告，读取原始网页或 PDF（记录页码），提取：学校、学院、专业代码、研究方向、学习方式、拟招生人数、推免人数、统考计划人数，并标注人数口径、核验状态与版本差异。

【三条硬性规则（写进代码强制执行）】
1. 人数只来自官方原文。来源域名必须属于 .edu.cn / .ac.cn / .gov.cn / chsi.com.cn；搜索引擎摘要、考研机构、论坛内容只能用于发现线索，非官方来源会被脚本直接拒收。
2. 禁止推算。不得用"拟招生 − 推免"倒推统考名额；缺少人数口径说明的记录不允许标记为"已核验"。
3. 不绕过访问限制。遇验证码、登录墙、付费墙立即停止，并在来源日志中登记失败原因。

【输出什么】
一个六工作表的 Excel（招生计划明细 / 采集报告 / 口径冲突 / 来源日志 / 学校清单 / 字段说明），明细页已开自动筛选，可按省份、学校、学院、专业代码、拟招生人数筛选；另附 Markdown 采集报告，列出已完成与未完成学校、缺失数据、异常数据与待人工核验项。数据以追加方式写入，每次写入前自动快照，多版本公告并存不覆盖。

【适用与不适用】
适用：某年、某省或某几所高校的硕士招生计划整理与核对；核实某校某专业是否招生、招多少人。
不适用：本科招生、博士招生、报录比与分数线统计；需登录或验证码才能访问的页面。

【环境与许可】
Python 3.9+，依赖 openpyxl。开源 MIT。
源码：https://github.com/Doting-du/cn-grad-admission-collector

【重要提示】
输出为各校计划口径数据，可能与实际录取人数不同，不构成报考建议；"待核验"项请点开原文自行确认。
```
