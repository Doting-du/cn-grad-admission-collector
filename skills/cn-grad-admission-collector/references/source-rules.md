# 官方来源与人数口径规则

## 一、来源优先级（决定「能否作为人数依据」）

| 级别 | 来源 | 可否作为人数依据 | 说明 |
| --- | --- | --- | --- |
| A | 学校研究生院 / 研究生招生网发布的招生简章、招生专业目录（含 PDF 附件）、招生计划公告、调整公告 | 可以 | 首选。记录到「页/条」粒度 |
| B | 学院官网发布的《分专业招生计划》《复试录取实施细则》 | 可以 | 常含方向级人数，权威性略低于研招网，但同校口径可能不同，须标注 |
| C | 中国研究生招生信息网 yz.chsi.com.cn 硕士专业目录查询 | 可以 | 学校自行填报的官方库；与校内文件不一致时保留双方数值 |
| D | 省级教育考试院 / 教育厅公告 | 仅作范围确认 | 通常无分专业人数 |
| E | 搜索引擎摘要、考研机构、论坛、公众号、往年数据 | **不可以** | 只能用于发现线索与定位 A/B/C 级原文 |

判定硬规则：`source_url` 的域名必须属于 `.edu.cn`、`.ac.cn`、`.gov.cn`、`chsi.com.cn`。
不满足时 `append_records.py` 直接拒收；确需保留线索须加 `--allow-nonofficial`，该记录会被强制标为「待核验」。

## 二、站点与文件定位方式

1. 研究生院 / 研招网常见子域：`yjsy.` `yjs.` `gs.` `grs.` `yz.` `yzb.` `grad.` + 学校主域，例如
   `yz.tsinghua.edu.cn`、`gs.whu.edu.cn`、`yzb.seu.edu.cn`、`grawww.nju.edu.cn`。
2. 招生专业目录入口常见路径段：`/zsml/` `/zyml/` `/zsxx/` `/yjszs/` `/info/` `/2027/`，
   文件名常含「招生简章」「招生专业目录」「招生计划」「专业一览表」。
3. 研招网单位页：`https://yz.chsi.com.cn/sch/schoolInfo--schId-<数字>.dhtml`；
   硕士专业目录查询：`https://yz.chsi.com.cn/zsml/queryAction.do`（按年份、省份、门类检索）。
4. PDF 优先于网页摘要；PDF 必须记录读取到的页码（如 `P12-14 表3`），便于复核。
5. 每年 9 月发简章与目录、10 月常有调整公告、次年 3 月发复试细则（可能再调分方向计划）。
   检索时按这三波依次检查，不能只看 9 月版本。

## 三、人数口径陷阱（务必逐条排查）

1. **学院口径 ≠ 专业口径**：目录「拟招生人数」常是学院/一级学科总数，须读表头与备注。
2. **是否含推免**：多数目录含推免；部分学校仅在备注写「含推免 X 人」。原文没写就不得假设。
3. **只发统考计划**：少数学校目录只列统考拟招，推免另发章程 —— 此时不得把该数当「拟招生总数」。
4. **学习方式分列**：同一专业代码下全日制/非全日制人数分开，必须分成两条记录。
5. **专项计划单列**：少数民族骨干、退役大学生士兵等专项名额不计入普通计划。
6. **模糊表述**：「约 30 人」「30 左右」「≤30」不得取整当确定值 —— 原样记录、标「待核验」。
7. **拟招生 ≠ 实际录取**：实际录取以拟录取公示为准，字段只能填「拟招生」类数据。
8. **同一专业多方向**：人数若只到专业级，方向行的人数应留空并在备注注明「人数为专业级口径」。

## 四、禁止的推算

- 禁止 `统考计划 = 拟招生 − 推免`，除非原文明确写「统考拟招 X 人」。
- 禁止用往年人数、报录比、学院总人数倒推。
- 禁止在不同学校/年份间套用同一比例。
- 数值不自洽（统考 ≠ 拟招生 − 推免）时保留三个原始数值，标「待核验」，交人工判断，不做修正。

## 五、跨来源不一致时的处理

1. 两条记录都保留，各自带 `source_url` 与 `publish_date`。
2. `conflicts.csv` 自动生成差异条目（字段、两方数值、两方来源）。
3. 能判定新旧关系时：新公告行填 `is_current=当前采用`，旧行填 `is_current=历史版本`，
   并在备注写「被 YYYY-MM-DD 公告替代」。**不删除历史行**。
4. 不能判定时：两行都保持 `is_current=当前采用`，核验状态标「口径冲突」，列入报告待人工核验。

## 六、访问受限的处理（合规红线）

| 情形 | 动作 |
| --- | --- |
| 图形/滑块验证码 | 立即停止，不得尝试识别或绕过；`access_result=验证码拦截` |
| 需登录 / 校内 IP / 付费墙 | 停止；`access_result=需登录` 或 `权限限制`；改找同一公告的公开页 |
| 404 / 链接失效 | `access_result=404/已下线`；回站内检索同标题新链接 |
| PDF 为扫描件无法取文 | `access_result=PDF无法解析`；如用 OCR 必须在备注写「OCR 结果，待核验」 |
| 超时 / 反爬封禁 | 最多重试 2 次（间隔 ≥3 秒），仍失败即记录并跳过 |

统一要求：失败情形必须写入 `sources.csv`（`append_records.py` 支持 `{"sources": [...]}` 批量登记），
并在报告中体现。禁止更换 UA、伪造 Cookie、调用打码服务、构造站内接口参数等规避手段。
