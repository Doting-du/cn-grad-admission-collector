# 数据结构与字段定义

## 一、任务目录结构

```
<run_dir>/
├── run.json                  # 年份、省份范围等运行配置
├── data/
│   ├── records.csv           # 主数据表（append-only，写入前自动备份）
│   ├── sources.csv           # 来源登记与访问结果（含失败/受限记录）
│   ├── conflicts.csv         # 跨来源数值差异
│   ├── schools.csv           # 学校清单与进度
│   └── history/              # 每次写入前的历史快照（修改日志）
├── sources/                  # 存档的原始 PDF / HTML（建议命名为 学校_材料_日期.pdf）
├── logs/collection_log.md    # 追加式操作日志
├── 考研招生计划_<年份>.xlsx
└── 采集报告_<年份>.md
```

CSV 一律 UTF-8 with BOM，可直接用 Excel 打开编辑，脚本能读回。中文表头与英文字段名均可被识别。

## 二、主数据表字段（records.csv）

| 字段 | 中文名 | 填写规则 |
| --- | --- | --- |
| year | 招生年份 | 四位数字，按简章标题归属年 |
| province | 省份 | 学校所在省级行政区简称（北京/内蒙古/广西…） |
| school | 学校名称 | 官方全称，不含「大学研究生院」等后缀 |
| school_code | 学校代码 | 教育部 5 位代码（个别 4 位），取自研招网或简章封面 |
| college | 学院名称 | 官方全称 |
| college_code | 学院代码 | 目录中学院代码，可空 |
| major | 专业名称 | 目录中的正式专业名称 |
| major_code | 专业代码 | 6 位，可加 2 位方向码（085400 / 085400-01） |
| direction | 研究方向 | 原文方向名，保留编号与空格 |
| study_mode | 学习方式 | 全日制 / 非全日制 / 全日制/非全日制 / 不区分 |
| exam_mode | 考试方式 | 全国统考 / 推荐免试 / 单独考试 / 管理类联考 / 法律硕士联考 / 不区分 |
| planned_total | 拟招生人数 | **仅当原文明确给出该行拟招总数时填写** |
| recommend_quota | 推免人数 | 仅当原文明确列出推免/拟接收推免数时填写 |
| unified_quota | 统考计划人数 | 仅当原文明确单列统考名额时填写，禁止减法推算 |
| quota_basis | 人数口径说明 | 抄录原文对口径的表述（含/不含推免、专业级或学院级、是否含非全） |
| source_title | 原文标题 | 与网页/PDF 标题一致 |
| source_type | 材料类型 | 招生简章 / 专业目录 / 招生计划 / 调整公告 / 复试录取办法 / 其他 |
| source_url | 来源网址 | 原始页面或 PDF 直链，须为官方域名 |
| publish_date | 发布日期 | YYYY-MM-DD |
| verify_status | 核验状态 | 已核验 / 待核验 / 口径冲突 / 无数据 |
| is_current | 版本 | 当前采用 / 历史版本 |
| collected_at | 采集时间 | 脚本自动补 |
| notes | 备注 | 口径补充、替代关系、OCR 说明等 |
| record_id | 记录ID | 脚本自动分配（R00001…），勿手改 |

## 三、核验状态流转

| 状态 | 含义 | 触发条件 |
| --- | --- | --- |
| 已核验 | 已打开官方原文，字段逐一对应 | 必填项齐全 + 有人数口径说明 + 有发布日期 |
| 待核验 | 口径不明、数值缺失、日期缺失、来源为线索 | 脚本自动降级，或人工标注 |
| 口径冲突 | 多来源数值不一致且无法判定采用版本 | 冲突未解决时人工标注 |
| 无数据 | 官方材料未公布该项人数 | 明确查证过目录/公告无该数据 |

脚本强制规则：无 `quota_basis` 时不允许停留在「已核验」；缺 `publish_date` 时同样降级。

## 四、其他表

- **sources.csv**：每访问一个原始材料登记一行。`access_result` 枚举：成功 / 404/已下线 / 需登录 / 验证码拦截 / 权限限制 / PDF无法解析 / 超时/网络失败。失败情形必须留痕。
- **conflicts.csv**：脚本按「学校+专业代码+方向+学习方式+考试方式」比对，`field` 记冲突字段，保留双方数值与来源，`resolution` 记处理说明。
- **schools.csv**：`status` 枚举：待检索 / 检索中 / 已完成 / 部分完成 / 未完成 / 访问受限。有记录只会自动置「部分完成」，改「已完成」须人工确认全量覆盖。

## 五、Excel 工作簿结构

| Sheet | 内容 |
| --- | --- |
| 招生计划明细 | 全字段、自动筛选、冻结首行与首列；核验状态按颜色高亮；三项人数全空的行标灰 |
| 采集报告 | 进度指标、待核验/冲突/缺失/异常计数、数据边界声明 |
| 口径冲突 | 跨来源差异明细 |
| 来源日志 | 访问结果与问题记录 |
| 学校清单 | 逐校状态与记录条数 |
| 字段说明 | 每个字段的填写规则（随表交付，便于复核） |

筛选方式：`招生计划明细` 已开启自动筛选，可直接按省份、学校名称、学院名称、专业代码、拟招生人数、
核验状态做文本/数值筛选；人数列为数值型，支持「大于/介于」等数值筛选。
