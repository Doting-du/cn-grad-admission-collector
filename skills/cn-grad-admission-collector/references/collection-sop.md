# 逐校采集 SOP 与验收清单

## 一、单所学校标准动作（按顺序执行，不要跳步）

1. **定位研招入口**：用「学校名 + 2027 硕士研究生招生简章」「学校名 + 招生专业目录」检索，
   只取 `.edu.cn` / `.ac.cn` / `chsi.com.cn` 结果；把研招网/研究生院首页地址写入 `schools.csv`。
2. **下载/打开招生简章**：确认报考条件、招生方式、目录发布位置（多数简章末尾挂目录 PDF）。
3. **打开专业目录原文**：优先 PDF；记录到页码（如 `P12 表3`）。扫描件按「PDF无法解析」处理。
4. **定位目标学院/专业**：按学院逐段读取；若目录按一级学科汇总，注意备注中的方向人数。
5. **抄录口径**：把表头说明、备注中关于人数的句子原文抄进 `quota_basis`。
6. **判读人数**：分别判断能否填 `planned_total` / `recommend_quota` / `unified_quota`；
   不确定的一律留空，不得推算。
7. **检查第二波材料**：站内近 3 个月是否有「招生计划调整」「补充公告」；有则新增记录并
   把旧记录改 `is_current=历史版本`。
8. **登记来源**：成功与失败都写入 `sources.csv`（含 `access_result`）。
9. **入库校验**：把本批记录写成 JSON 交给 `append_records.py`，逐条处理脚本返回的
   `warnings`（尤其是「数值关系不自洽」「缺口径说明」）。

## 二、检索关键词模板

- `<学校> 2027年硕士研究生招生简章`
- `<学校> 2027年硕士研究生招生专业目录 filetype:pdf`
- `<学校> <学院> 2027 招生计划`
- `<学校> 2027 硕士研究生招生计划调整 公告`
- 站内检索：`site:<学校域名> 2027 专业目录`
- 研招网核对：`https://yz.chsi.com.cn/zsml/queryAction.do` 选年份+省份+门类

## 三、单校完成判据

- 目标学院（或用户指定专业）在最新版目录中**逐专业/方向**都有一条记录，或明确标「无数据」；
- 每条记录都有官方 `source_url` + `publish_date` + `quota_basis`；
- 已检查是否存在调整公告，并在 `notes` 说明当前采用版本；
- `sources.csv` 至少 1 条成功记录，失败访问也已登记；
- `schools.csv` 的 `status` 人工改为「已完成」（部分学院未取全则「部分完成」）。

## 四、试运行（默认 5 所）验收清单

首次运行只做 5 所学校，交付后请用户按下列 5 点核对，确认后再扩量：

| # | 验收项 | 通过标准 |
| --- | --- | --- |
| 1 | 来源可点开 | 任取 3 条记录，点链接能打开原页面/PDF，且标题一致 |
| 2 | 数字对得上 | 原文数字与表中 `拟招生人数` 一致，不是机构口径 |
| 3 | 口径说得清 | `quota_basis` 能让第三方判断「含不含推免、是专业级还是学院级」 |
| 4 | 缺口标得出 | 未公布人数的项确实标了「无数据/待核验」，没有凭空填数 |
| 5 | 字段够用 | 用户确认字段集合（是否需增加「学制」「学费」「复试科目」等） |

用户反馈字段需增删时，改 `scripts/common.py` 的 `RECORD_FIELDS`（表头+宽度）与
`export_excel.py` 的字段说明表，再重跑导出；已采集数据按 key 自动对齐，无需重录。

## 五、扩量顺序

1. 按省份成批推进（一省一批），每批结束导出一次 Excel，便于中途抽查。
2. 优先 985/211 与用户指定专业强势院校（材料规范、目录齐全，成功率最高）。
3. 材料只发布在学院官网的学校单独成批（耗时高、口径最杂）。
4. 每批结束都追加日志：`append_records.py --batch 江苏批次`。

## 六、常见失败与对策

| 现象 | 对策 |
| --- | --- |
| 目录只有学院总数 | 人数记在学院汇总行，专业行人数留空并备注 |
| 目录 PDF 按图片扫描 | 标「PDF无法解析」；如 OCR，须在备注注明并保持「待核验」 |
| 简章页有目录但附件 404 | 换站内检索同标题，或退到研招网专业目录库（C 级来源）并标注 |
| 同校两个学院口径不同 | 分行记录，各自 `quota_basis` 写清，交人工判断是否合并 |
| 用户要求「补齐所有学校」 | 先跑 5 校验收；未验收不得批量扩量（避免口径错误被放大） |
